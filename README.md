This folder contains the scripts used in Lafuente-Gracia et al., Mind the gap: Sex-specific computational modeling reveals distinct mechanisms in bone fracture healing, submitted to _Biology of Sex Differences_ in April 2026.
Specifically,
1. MATLAB script of the sex-specific model of bone fracture healing
2. Folder 'Sobol-GSA' contains the MATLAB scripts used to perform the variance-based global sensitivity analysis using Sobol indices, as well as the two R scripts used to plot the heatmaps of Figure 3
